# Working Style

- Keep solutions simple.
- Do not overengineer.
- Prefer the smallest correct change.
- Do not rewrite unrelated files.
- Do not scan the whole repo unless necessary.
- Read only files relevant to the task.
- Reuse existing components, patterns, and dependencies.
- Avoid unnecessary abstractions.
- Avoid unnecessary new dependencies.
- Keep terminal commands and output concise.
- Do not explain obvious steps unless asked.
- If something already works, do not refactor it just for cleanliness.
- Fix the actual root cause, not surrounding code.
- Verify changes before finishing.
- Stop once the requested task is complete.

# Context and Token Efficiency

- Use targeted file searches.
- Do not repeatedly reread unchanged files.
- Summarize large outputs instead of dumping them.
- Avoid broad exploratory commands when a narrow one will work.
- Prefer editing known relevant files over repository-wide investigation.
- Keep responses short unless deeper explanation is requested.
